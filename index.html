Bắt đầu triển khai

Cài đặt và chạy thử ROS 2

Lệnh minh họa cho hệ điều hành Linux có ROS 2 Jazzy hoặc Humble. Dùng đúng package ROS 2 gốc lidar_localization_ros2; tên repository Việt hóa là vi-lidar.

1. Tải repository Việt hóa và biên dịch

mkdir -p ~/lidarloc_ws/src
cd ~/lidarloc_ws/src
git clone https://github.com/xulytiengviet/vi-lidar.git lidar_localization_ros2
cd lidar_localization_ros2
scripts/bootstrap_colcon_workspace.sh --build
source ~/lidarloc_ws/install/setup.bash

2. Cấp dữ liệu và định vị trên bản đồ

Khởi động driver LiDAR và nguồn odometry nếu có; sau đó mở quickstart:

ros2 run lidar_localization_ros2 quickstart.py \
  --map /duong/dan/tuyet/doi/map.pcd

ros2 run lidar_localization_ros2 \
  check_lidar_localization_bringup.py --profile standalone

3. Tùy chọn điều hướng bằng Nav2

ros2 launch lidar_localization_ros2 nav2_navigation.launch.py \
  map_yaml:=/duong/dan/tuyet/doi/map.yaml

Nav2 cần thêm bản đồ chiếm chỗ 2D và phép biến đổi odom → base_link. Trong chế độ Nav2, bộ định vị cung cấp map → odom. Cần bảo đảm mỗi biến đổi TF chỉ có một nguồn phát.

Điều kiện cần kiểm tra

  • ROS 2 Jazzy (ưu tiên) hoặc Humble, máy Linux đủ tài nguyên xử lý point cloud.
  • Bản đồ .pcd/.ply đã được tạo và hệ tọa độ nhất quán với robot.
  • Topic LiDAR và các TF cảm biến hoạt động; odometry/IMU có thể hỗ trợ.
  • Nếu không đủ tin cậy, dùng 2D Pose Estimate trong RViz thay vì ép hệ thống đoán.
  • Không chạy điều hướng thực tế chỉ dựa vào mô phỏng web; phải có cơ chế an toàn dừng robot.
